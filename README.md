# Dsidebar
一款功能强大的浏览器侧边栏 AI 助手插件，集成了**翻译、聊天、搜索**三大核心功能，旨在提升您的网页浏览和信息处理效率。

## ✨ 主要功能

- **🚀 三大核心模式**：
  - **AI 翻译**：支持划词翻译、右键菜单翻译和在侧边栏直接输入文本翻译。可自定义翻译的专业领域、目标受众、语气，并支持专业词汇表。
  - **AI 聊天**：与先进的 AI 模型进行连续对话，解答问题、获取灵感、编写代码等。
  - **AI 搜索**：结合实时网络搜索结果，提供有信息来源、更可靠的综合性回答。

- **🔧 高度可配置**：
  - **多 API 支持**：支持接入任何兼容 OpenAI 协议的 API 以及 Google Gemini 原生 API。
  - **API 方案管理**：可预设多套 API 配置（URL, Key, Model），并在不同功能间独立切换使用。
  - **专业词汇表**：为翻译功能创建和管理多个词汇表，确保专业术语的准确性。
  - **自定义搜索**：可配置搜索角色、Tavily API 密钥，并能设定在特定网站域名内进行搜索。

- **📝 智能与效率**：
  - **咒语 (Prompts) 管理**：内置强大的咒语管理器，可创建、编辑、导入/导出常用的提示词模板，一键取用。
  - **历史记录**：自动保存翻译、对话和搜索历史，方便随时回顾和恢复会话。
  - **便捷交互**：支持`Alt + 划词`、右键菜单快速唤起翻译，提供固定侧栏和悬浮菜单两种 UI 模式。

## 🛠️ 技术栈

- **核心框架**: HTML5, CSS3, JavaScript (ES6+)
- **Markdown 渲染**: [marked.js](https://github.com/markedjs/marked)
- **打包方式**: 原生 Chrome Extension (Manifest V3)

## 📦 安装指南

由于此插件未上架 Chrome 网上应用店，您需要通过开发者模式手动安装。

1.  **下载代码**：
    -   访问本项目的 [GitHub 页面](https://github.com/caiyajunx/Dsidebar)。
    -   点击绿色的 `Code` 按钮，然后选择 `Download ZIP`。
    -   将下载的 `ZIP` 文件解压到你电脑的一个固定位置。

2.  **在 Chrome 中安装**：
    -   打开 Chrome 浏览器，在地址栏输入 `chrome://extensions` 并回车。
    -   在页面右上角，打开“**开发者模式**”的开关。
    -   点击页面左上角的“**加载已解压的扩展程序**”按钮。
    -   在弹出的文件选择窗口中，选择你刚刚解压的那个文件夹（例如 `ai-assistant-chrome-extension-main`）。
    -   安装成功后，AI 助手图标会出现在你的浏览器工具栏上。点击它即可打开侧边栏。

## ⚙️ 使用前配置

**这是必须的步骤！** 本插件需要您提供自己的 API 密钥才能正常工作。

1.  点击浏览器工具栏上的插件图标，打开侧边栏。
2.  在侧边栏导航中，点击**设置**图标。
3.  切换到 **API 设置** 标签页。
4.  选择一个默认的配置方案（如 Deepseek-V3）或新建一个。
5.  填入您的 **API Key** 和其他必要信息（如 API URL、模型名称）。
6.  如果您需要使用**搜索**功能，请切换到 **搜索设置** 标签页，并填入您的 [Tavily AI](https://tavily.com/) 的 API 密钥。
7.  配置完成后，即可开始使用所有功能。

## 🚀 如何使用

- **打开/关闭侧边栏**：点击浏览器工具栏上的插件图标。
- **快速翻译**：
    1.  在任何网页上，按住 `Alt` 键的同时用鼠标选择一段文本。
    2.  或者，选择一段文本后，点击鼠标右键，在菜单中选择“使用 AI 助手翻译”。
- **模式切换**：在侧边栏左侧的导航条中，点击不同的图标（翻译、聊天、搜索等）来切换功能模式。
- **UI 模式切换**：在导航条底部，可以通过“收起/展开”按钮在固定的窄边栏模式和悬浮菜单模式之间切换。
