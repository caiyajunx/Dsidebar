# Dsider 助手 V2.0

Dsider 是一个基于 Manifest V3 的 Chrome 侧边栏扩展，面向药物研发信息工作流，提供 AI 翻译、聊天、AI 搜索、Prompt 管理和本地配置管理。它还可在侧边栏中打开玻尔、Aily、IMA、问答、KIMI、豆包等站点，并支持添加自定义工具入口。

## 功能概览

- **翻译**：支持自定义翻译指令、目标语言、术语表和翻译历史；可通过右键菜单翻译选中文本，也可在设置中启用划词浮动翻译按钮。
- **聊天**：使用已配置的模型进行单轮或连续对话，并保存对话历史。
- **AI 搜索**：提供“简洁”和“深度”模式。简洁模式基于检索摘要生成回答；深度模式会先筛选高价值结果、抓取原文证据，再生成回答。搜索为单次任务，不是多轮对话。
- **药物研发数据源**：可组合 Tavily、指定域名、OpenFDA 药品标签和 ClinicalTrials.gov 试验登记数据；可配置来源优先级、回答模板和行业搜索画像。
- **Prompt 与设置**：支持 Prompt 分类管理、导入/导出、多个 API 配置方案、多个 Tavily Key 轮询、导航显示控制和界面布局设置。

## 安装与首次配置

1. 打开 Chrome 的 `chrome://extensions`，启用“开发者模式”。
2. 选择“加载已解压的扩展程序”，并选择本项目根目录。
3. 点击扩展图标打开侧边栏，进入“设置”。
4. 在“API 设置”中填写 API URL、模型名称和 API Key，或选择“导入示例配置”后补充自己的 Key。
5. 对自定义 API URL 点击“授权此 API 域名”；扩展会请求该域名的访问权限。
6. 如需联网搜索，在“搜索设置”中填写 Tavily API Key（可添加多个 Key 轮询）。

翻译、聊天和搜索均需要配置相应的模型 API。即使不使用 Tavily，搜索仍需要搜索模型 API 来整理公开数据源返回的结果。

## 搜索说明

- **简洁模式**：并行检索 Tavily、已启用的指定域名和公开药物数据源，再根据结果摘要生成回答。
- **深度模式**：在上述检索后用模型筛选高价值来源，获取原文证据，并基于证据作答；原文提取失败的内容会明确作为搜索摘要处理。
- **无需 Tavily 的情形**：当 OpenFDA 或 ClinicalTrials.gov 返回结果时，仍可使用公开数据搜索；若两者均无结果，需配置 Tavily 或调整检索词。
- **公开数据源**：OpenFDA 当前用于药品标签检索，可选 access key 用于提高 API 限额；ClinicalTrials.gov 用于临床试验登记检索，二者默认均不需要 Key。

建议按“有效成分（INN/通用名）+ 商品名 + 公司 + 目标维度”组织问题，例如：

`奥希替尼（Osimertinib / 泰瑞沙 / AstraZeneca）80 mg 片剂辅料与批准说明书`

对于审批报告，可加入“剂型、规格、毒性、杂质、assessment report、PAR、interview form”等限定词。对于制剂处方，俄语/西语来源可配合 `Вспомогательные вещества`、`Fórmula`、`composicion`、`anmat` 检索。

试验登记状态不等同于疗效结论，自发不良事件报告不能推断发生率或因果关系。本扩展仅用于研发信息检索，不提供诊疗建议。

## 私有配置与安全

API Key 保存在 Chrome 本地存储中；“导出配置”会生成 `dsider_private_settings_YYYY-MM-DD.json`，其中可能包含 API Key。请妥善保管，不要上传到 GitHub；该文件名已被 `.gitignore` 排除。

导入配置会覆盖当前本地设置，仅应导入可信来源的文件。“导入示例配置”只添加 API 地址、模型和搜索画像，不会写入或覆盖 API Key。

仓库中的默认配置与示例配置均不包含真实 Key。发布前请扫描 `tvly-`、`sk-`、`api_key`、`apikey`、`secret`、`token`、`Bearer` 等敏感关键词；新增服务商时只添加空 Key 示例，并同步检查 `manifest.json` 的 `host_permissions`。
